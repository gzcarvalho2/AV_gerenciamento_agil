# AV_gerenciamento_agil

Trabalho em grupo da disciplina de Gerenciamento Ágil de Projetos (curso de Análise e
Desenvolvimento de Sistemas), desenvolvido ao longo de 8 sprints e uma entrega final
(08/05/2026 a 03/07/2026). O grupo aborda cinco temas do ecossistema ágil — Design
Thinking, Lean e Agilidade, Kanban, eXtreme Programming (XP) e DDD — aprofundando o
conteúdo a cada sprint, do conceitual à aplicação prática, usando como fio condutor o
projeto fictício **Scrunic**, uma plataforma de gestão de tarefas com quadro Kanban.
